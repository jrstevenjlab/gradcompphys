# Unit 1 Resources: Research Computing Foundations

Related pages: [Resources Home](./README.md) | [Syllabus](../syllabus.md) | [Assignments](../assignments/README.md)

This unit focuses on the habits and tools that make computational research reliable and collaborative: Unix/Linux workflows, Git, Python environments, array-based scientific computing, plotting, tabular data analysis, and reproducible project organization.

## Essential

- [Software Carpentry lessons](https://swcarpentry.github.io/)  
  Start here for the Unix shell, version control with Git, and programming with Python in a research context.
- [Pro Git](https://git-scm.com/book/en/v2)  
  A practical, readable reference for everyday Git usage and collaboration.
- [Python 3 documentation](https://docs.python.org/3/)  
  Use the tutorial, library reference, and packaging guidance throughout the course.
- [NumPy documentation](https://numpy.org/doc/stable/index.html)  
  The core reference for arrays, vectorized operations, linear algebra basics, and numerical workflows.
- [SciPy documentation](https://docs.scipy.org/doc/scipy/)  
  A central reference for optimization, integration, interpolation, statistics, and scientific utilities.
- [Matplotlib documentation](https://matplotlib.org/stable/)  
  The main resource for plotting, figure customization, and publication-quality graphics.
- [pandas documentation](https://pandas.pydata.org/pandas-docs/stable/)  
  Useful for tabular data cleaning, indexing, grouping, reshaping, and data import/export.

## Recommended

- [Effective Computation in Physics](https://www.oreilly.com/library/view/effective-computation-in/9781491901564/)  
  Strong coverage of command-line work, automation, testing, version control, and project organization for physical science workflows.
- [Python Data Science Handbook](https://jakevdp.github.io/PythonDataScienceHandbook/)  
  A practical reference for NumPy, `pandas`, Matplotlib, and notebook-based analysis.
- [pandas Getting Started](https://pandas.pydata.org/getting_started.html)  
  A good quick path into data structures, indexing, and basic tabular workflows.

## Optional Deeper Reading

- [Git user manual](https://git-scm.com/docs/user-manual)  
  Helpful once the basic `clone`-`add`-`commit`-`push` workflow feels comfortable.

## Suggested Unit Focus

- Learn the shell well enough to navigate, inspect files, and automate simple tasks.
- Use Git frequently enough that commits become part of normal working practice.
- Build analysis scripts that can be rerun from raw inputs to final figures.
- Prefer clear project structure and short documentation over ad hoc notebook-only workflows.
